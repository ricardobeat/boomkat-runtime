boomkat runtime

A small JavaScript runtime on the boomkat engine, uWebSockets and OpenSSL, with fine-grained permission control.

read the docs open in github (opens in a new tab)

try it now

$ curl https://boomkat.run/install | sh

features

permissions
--allow-net, --allow-read and --allow-write, scoped to hosts or paths
http
standards-based server with routes, TLS and WebSockets
TSX serving
transpiles TSX to browser JavaScript, with source maps
sqlite
optional built-in with prepared statements and transactions
workers
module workers that inherit the parent's permissions
packages
plain ESM - clean break from npm

built-in modules

http
serve, upgradeWebSocket
net
TCP and TLS connect, listen, DNS resolve
file
read, write, open, stat, list, mkdir, copy
process
args, env, stdio, spawn, run
path
join, resolve, relative, file URLs
crypto
random bytes, sha256, password hashing, subtle
typescript
type erasure and JSX lowering with source maps
test
test, describe, hooks and assertions

example

// hello.js
import { serve } from "http";

serve({
  port: 8080,
  fetch(req) {
    return new Response("hello");
  },
});
$ bkr --allow-net hello.js
