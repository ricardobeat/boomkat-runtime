boomkat runtime

A small JavaScript runtime on the boomkat engine, uWebSockets and OpenSSL, with fine-grained permission control.

features

permissions
--allow-net, --allow-read and --allow-write, scoped to hosts or paths
http
standards-based server with routes, TLS and WebSockets
TSX serving
transpiles TSX to browser JavaScript, with source maps
sqlite
optional built-in with prepared statements and transactions
workers
module workers that inherit the parent's permissions
packages
plain ESM - clean break from npm

example

// hello.js
import { serve } from "http";

serve({
  port: 8080,
  fetch(req) {
    return new Response("hello");
  },
});
$ bkr --allow-net hello.js
