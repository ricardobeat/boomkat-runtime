Serve TSX, HTTPS, and WebSockets

Transpile browser TypeScript and JSX at startup with source maps, upgrade HTTP requests to WebSockets, and serve HTTPS with PEM certificates.

Transpile TypeScript and TSX for the browser

The built-in typescript module uses Boomkat's parser to strip types and lower JSX to JavaScript without an external build step. Compile your client entry at startup and attach it as a static buffered Response in routes so it is served directly from native memory without entering JavaScript on each request: 

import { serve } from "http";
import { readText } from "file";
import { transpileWithMap } from "typescript";

const source = await readText("./app.tsx");
const { code, map } = transpileWithMap(source, {
  filename: "app.tsx",
  jsxImportSource: "preact",
});

serve({
  port: 8080,
  routes: {
    "/app.js": new Response(`${code}\n//# sourceMappingURL=/app.js.map`, {
      headers: { "content-type": "text/javascript; charset=utf-8" },
    }),
    "/app.js.map": new Response(map, {
      headers: { "content-type": "application/json; charset=utf-8" },
    }),
  },
});

For a single self-contained file during development, pass { sourceMap: "inline" } to transpile(source, options) instead. Automatic JSX emits imports from <jsxImportSource>/jsx-runtime; include an importmap in your HTML so the browser resolves bare specifiers to your served vendor routes.

Upgrade HTTP requests to WebSockets

Call upgradeWebSocket(req, { protocol }) inside any route or fetch handler. Attach listeners to socket and return response to complete the handshake: 

import { serve, upgradeWebSocket } from "http";

serve({
  port: 8080,
  routes: {
    "/ws": (req) => {
      if (req.headers.get("upgrade") !== "websocket") {
        return new Response("upgrade required", { status: 426 });
      }
      const { socket, response } = upgradeWebSocket(req);
      socket.onmessage = (e) => socket.send(e.data);
      return response;
    },
  },
});

Enable HTTPS with TLS certificates

Pass tls: { cert, key } to serve() with paths to PEM-encoded certificate and private key files. Both files require read permission, and OpenSSL 3 must be present at run time: 

import { serve } from "http";

serve({
  port: 8443,
  tls: { cert: "./cert.pem", key: "./key.pem" },
  fetch() {
    return new Response("secure");
  },
});

serve({ tls }) runs on a single HTTP thread and cannot be combined with --http-workers or --http-processes. Terminate TLS in a reverse proxy in front of multi-worker pools.
