CLI commands, flags, and boomkat.toml

Command-line invocation modes, permission flags, scaling options, and boomkat.toml syntax.

CLI commands

CommandBehavior
bkr [flags] <script> [args...]Evaluate <script> (.js, .mjs, .jsx, .ts, .mts, .tsx) as an ES module with top-level await. Trailing arguments populate args in the process module.
bkr [flags] [repl]Start an interactive REPL when no script path is given. Supports top-level await, _ (last value), _error (last error), .help, .clear, and .exit.
bkr test [flags] [--watch] [--filter=text] [paths...]Discover and run *.test.*, *_test.*, and *.spec.* files under paths (or .). Exits with status 1 on any failure or if no test files are found.
bkr check <script>Scan the static local module graph of <script>, print imported built-in modules, and suggest the --allow-* flags required.

Permission and sandbox flags

FlagEffect
--allow-<perm>[=a,b]Grant an entire permission category, or restrict it to a comma-separated allowlist.
--deny-<perm>=a,bDeny matching items. Deny rules always override allow rules and -A.
-A, --allow-allGrant all permission categories.
--prompt / --no-promptEnable or disable interactive [y/n/A] prompts on /dev/tty. Prompting defaults to on when both stdin and stderr are TTYs.
--no-sandboxDo not apply the macOS Seatbelt OS sandbox (or silence the missing-sandbox warning on Linux) when prompting is disabled.
--config <file>Load permissions from <file> instead of looking for boomkat.toml beside the entry script.

Execution and HTTP scaling flags

FlagEffect
--time-limit=<ms>Interrupt any synchronous JavaScript turn (or SQLite query) that runs longer than <ms> milliseconds. HTTP requests return 500; other turns exit with status 1.
--http-workers=<1..64>Run N in-process server VMs sharing one listener, distributing accepted connections round-robin.
--http-processes=<1..64>Run N isolated worker processes behind a native TCP acceptor that passes sockets over SCM_RIGHTS.
--jitEnable native JIT compilation on engines built with the SLJIT feature.

boomkat.toml format

Placed beside the entry script (or passed via --config). Relative paths in read and write are resolved against the directory containing the TOML file. Each permission key accepts a boolean (true or false) or an array of allowlist strings: 

[permissions]
prompt = false
net = ["127.0.0.1:8080", "*.example.com"]
read = ["./data"]
write = false
env = ["APP_*"]
run = ["git"]
