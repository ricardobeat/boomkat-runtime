reference

Built-in modules

Built-in modules are imported by bare specifier (for example, import { serve } from "http"). Any other bare specifier throws a module load error.

http — HTTP, HTTPS, and WebSocket server

Requires --allow-net for the bound hostname and port (plus --allow-read for TLS certificate and key files).

serve(options, fetch?) -> Server

Start an HTTP or HTTPS server on uWebSockets. options accepts hostname (default "0.0.0.0"), port (default 8080, or 0 for an ephemeral port), tls: { cert, key } (PEM file paths), routes, static, fetch(req, server), error(err), and onListen(server). routes maps paths (exact, :param, or terminal /*) to a handler function, a buffered Response snapshot, a per-method map (GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS, TRACE, CONNECT), or false to delegate to fetch. The returned Server exposes hostname, port, url (URL), workers, ready (Promise<Server>), finished (Promise<void>), stop(force = false), and [Symbol.asyncDispose]().

upgradeWebSocket(request, options?) -> { socket: WebSocket, response: Response }

Accept a WebSocket upgrade inside a route or fetch handler. options.protocol selects an offered subprotocol. Returns the server-side WebSocket (16 MiB message limit, 120 s idle timeout, automatic pings) and the 101 Response that the handler must return to complete the upgrade.

net — TCP, TLS, and DNS

Requires --allow-net.

connect({ hostname, port, tls = false }) -> Promise<Conn>

Open a TCP or TLS connection. When tls is true, verifies the peer certificate and hostname against the system root store using OpenSSL 3.

listen({ hostname = "0.0.0.0", port = 0 }) -> Listener

Bind a TCP listener. Returns an object with hostname, port, accept() -> Promise<Conn | null>, close(), and [Symbol.asyncIterator]().

resolve(hostname) -> Promise<string[]>

Resolve IPv4 and IPv6 addresses for hostname on the native thread pool.

Conn / Handle: { localPort, remoteAddress, remotePort, read(), write(data), closeWrite(), close(), readable, writable }

Resource handle for sockets, open files, and stdio pipes. read() resolves to a Uint8Array or null on EOF; write(data) accepts a Uint8Array, view, or string and resolves to the byte count written; readable and writable expose Web ReadableStream and WritableStream wrappers.

file — Filesystem operations

Requires --allow-read or --allow-write for the canonicalized target path. All paths accept a string or a file: URL.

body(path) -> FileBody

Create a lazy file body for new Response(body(path)). When passed untouched to the HTTP server, streams the file in 64 KiB chunks with socket backpressure and checks read permission when sending begins.

read(path) -> Promise<Uint8Array> · readText(path) -> Promise<string>

Read an entire file on the thread pool as bytes or UTF-8 text (stripping a leading UTF-8 BOM if present).

write(path, data, { append = false }?) -> Promise<null> · writeText(path, data, options?)

Write a string or byte buffer to path, creating or truncating the file by default, or appending when append: true.

open(path, mode = "r") -> Promise<Handle>

Open a file resource handle. mode may be "r", "w", "a", "x", or "rw".

stat(path) -> Promise<{ kind, size, mtime, mode }> · exists(path) -> Promise<boolean> · list(path) -> Promise<Array<{ kind, name }>>

Inspect file metadata via lstat (kind is "file", "dir", "symlink", or "other"; mtime is a Date), check whether a path exists, or list directory entries.

mkdir(path, { recursive = false }?) -> Promise<null> · remove(path, { recursive = false }?) -> Promise<null>

Create a directory or remove a file/directory.

rename(from, to) -> Promise<null> · copy(from, to) -> Promise<null>

Rename a path (requires write permission on both paths) or copy file contents from from to to.

process — Arguments, environment, stdio, and child processes

args: string[] · main: string · execPath: string · pid: number · exit(code = 0)

Script arguments after the entry filename, absolute path of the entry module, path to the running bkr binary, current process ID, and immediate process termination.

env: { get(name), set(name, value), delete(name), toObject() }

Read or modify environment variables (requires --allow-env for the variable name; toObject() requires an unrestricted --allow-env grant).

stdin: Handle · stdout: Handle · stderr: Handle

Resource handles for file descriptors 0, 1, and 2.

spawn(command, options?) -> Child · run(command, options?) -> Promise<{ code, stdout, stderr }>

Spawn a subprocess (requires --allow-run for command). options accepts args (string[]), env (Record<string, string>), cwd, and stdin / stdout / stderr ("inherit", "piped", or "null"). Child exposes pid, stdin, stdout, stderr, status (Promise<number>, negative signal number if killed), and kill(signal = 15). run() pipes stdout and stderr and resolves to their Uint8Array buffers and exit code.

path — POSIX path utilities

Pure path manipulation; requires no permissions except when resolve() reads the current working directory.

sep = "/" · delimiter = ":" · normalize(p) · join(...parts) · resolve(...parts) · relative(from, to) · isAbsolute(p)

Normalize, join, resolve against the working directory, compute relative paths, and test whether a path starts with /.

dirname(p) · basename(p, ext?) · extname(p) · parse(p) · format(obj)

Extract or reassemble { root, dir, base, ext, name } components.

toFileUrl(p) -> URL · fromFileUrl(url) -> string

Convert between filesystem paths and file:// URLs.

permissions — Runtime permission inspection

query(desc) -> Promise<{ state }> · request(desc) -> Promise<{ state }> · revoke(desc) -> Promise<{ state }>

Inspect, prompt for, or revoke permissions. desc is a category string or an object with name ("net", "read", "write", "env", "run", "ffi", "sys", "import") and an optional scope field (host, path, variable, command, or kind). state is "granted", "prompt", or "denied".

sqlite — Synchronous SQLite 3.31+ binding (optional)

Registered when the system SQLite shared library (3.31+) can be loaded at startup. File databases require --allow-read (and --allow-write when writable) for the database file and its -journal, -wal, and -shm sidecars.

new Database(path = ":memory:", { readonly = false }?)

Open an in-memory or file-backed database. Methods and getters: exec(sql), prepare(sql) -> Statement, query(sql) -> Statement, transaction(fn) -> fn (savepoint-backed synchronous wrapper), inTransaction: boolean, close(), and [Symbol.dispose](). ATTACH, VACUUM INTO, extension loading, and disk temp-store changes are blocked by an authorizer to enforce permission boundaries.

Statement: { all(...params), get(...params), run(...params), finalize(), [Symbol.dispose]() }

Reusable prepared statement. Parameters may be passed positionally, as a single array, or as a single named-parameter object (matching bare or :, $, @-prefixed SQL parameters). all() returns null-prototype row objects; get() returns the first row or undefined; run() returns { changes, lastInsertRowid }. 64-bit integers outside the safe Number range are returned as BigInts.

version: string

Loaded SQLite library version string (for example, "3.46.1").

crypto — Native hashing, Argon2id, and Web Crypto

randomBytes(size) -> Uint8Array · sha256(stringOrBytes) -> Uint8Array · hex(bytes) -> string

Generate cryptographically random bytes (0–65,536), compute a 32-byte SHA-256 digest, or format a Uint8Array as lowercase hexadecimal.

timingSafeEqual(a, b) -> boolean

Constant-time byte comparison via OpenSSL CRYPTO_memcmp for equal-length buffers; returns false immediately when lengths differ.

hashPassword(password) -> Promise<string> · verifyPassword(password, encoded) -> Promise<boolean>

Asynchronous Argon2id password hashing and verification on the thread pool (m=19456 KiB, t=2, p=1, 32-byte random salt, 32-byte output, max 4096 UTF-8 password bytes, at most 2 concurrent jobs before rejecting with code: "BUSY").

subtle: SubtleCrypto

Re-export of globalThis.crypto.subtle.

typescript — Native type erasure, JSX lowering, and source maps

transpile(source, options?) -> string

Strip TypeScript types and lower JSX to browser JavaScript using Boomkat's parser. options accepts filename (default "module.ts"; .tsx/.jsx enables JSX), module (default true), jsx ("automatic" or "classic"), jsxImportSource (default "preact"), jsxFactory (default "h"), jsxFragmentFactory (default "Fragment"), and sourceMap ("inline" or false).

transpileWithMap(source, options?) -> { code: string, map: string }

Return the transpiled JavaScript code (without a trailing sourceMappingURL comment) alongside a version 3 source map as JSON text.

test — Test registration, hooks, and assertions

test(name, fn) · it(name, fn) · describe(name, fn)

Register tests and suites for bkr test. Both test/it and describe support .skip(name, fn) and .only(name, fn); test.todo(name) records a placeholder.

beforeAll(fn) · afterAll(fn) · beforeEach(fn) · afterEach(fn)

Lifecycle hooks scoped to the current file or enclosing describe block. Hooks may be synchronous or async.

assert(cond, msg?) · assertEquals(a, b, msg?) · assertNotEquals(a, b, msg?) · assertStrictEquals(a, b, msg?) · assertMatch(text, regex, msg?) · assertThrows(fn, ErrorClass?, includes?) · assertRejects(fnOrPromise, ErrorClass?, includes?) · fail(msg?) · AssertionError

Assertion helpers. assertEquals performs deep structural comparison across plain objects, arrays, Map, Set, Date, RegExp, ArrayBuffer, and typed views, handling circular references.
