reference

Web-standard globals

Globals installed by the runtime prelude on globalThis in the main thread and inside module workers.

Fetch and HTTP primitives

fetch(input, init?) -> Promise<Response>

HTTP/1.1 client over net. Requires --allow-net for the target host and port; every redirect target (up to 20 hops) is re-checked against the net grants and strips Authorization and Cookie across origins. Verifies TLS certificates and hostnames on https: requests and automatically decodes gzip and deflate response bodies. Unread response bodies are unref'd so they do not keep the event loop alive.

Request · Response

Standard Fetch Request and Response classes. Both support body (ReadableStream), bodyUsed, text(), bytes(), json(), arrayBuffer(), blob(), and clone(). Response also provides Response.json(data, init?), Response.redirect(url, status = 302), and Response.error().

Headers

Case-insensitive header map with multi-value Set-Cookie preservation via getSetCookie().

URL · URLSearchParams

WHATWG URL (including URL.canParse and URL.parse) with a native fast path for plain http:/https: URLs, and URLSearchParams.

Blob · File

In-memory binary blobs with size, type, slice(), text(), bytes(), arrayBuffer(), and stream(). File extends Blob with name and lastModified.

WebSockets

new WebSocket(url, protocols?)

WebSocket client (and the class returned by upgradeWebSocket on the server). Client connections ride net over ws: or wss: (up to 64 MiB messages) and require --allow-net. Properties and methods: url, readyState, protocol, bufferedAmount, binaryType ("blob" or "arraybuffer"), send(data), close(code?, reason?), and open / message / error / close events.

CloseEvent

Event dispatched on WebSocket close with code, reason, and wasClean.

Streams and compression

ReadableStream · ReadableStreamDefaultReader

Standard default-controller readable streams with getReader(), pipeTo(), pipeThrough(), tee(), values(), [Symbol.asyncIterator](), and ReadableStream.from(iterable).

WritableStream · WritableStreamDefaultWriter

Writable stream and default writer with ready, closed, write(), close(), and abort().

TransformStream

{ readable, writable } transform pair.

TextEncoderStream · TextDecoderStream

Streaming UTF-8 encoder and decoder transforms (handling multi-byte sequences split across chunk boundaries).

new CompressionStream(format) · new DecompressionStream(format)

Streaming compression and decompression backed by system zlib. format may be "gzip", "deflate", or "deflate-raw".

Web Crypto

crypto.getRandomValues(typedArray) · crypto.randomUUID()

Fill an integer TypedArray (up to 65,536 bytes) with system randomness, or return a v4 UUID string.

crypto.subtle

Lazily initialized SubtleCrypto running on the native thread pool over OpenSSL 3. Supports digest (SHA-1, SHA-256, SHA-384, SHA-512), sign / verify (HMAC), encrypt / decrypt (AES-GCM, AES-CBC, AES-CTR), deriveBits / deriveKey (PBKDF2 up to 20M iterations, HKDF), and generateKey / importKey / exportKey for raw and jwk (oct) secret keys.

Workers and structured cloning

new Worker(url, { type = "module", name = "" }?)

Spawn an isolated module worker thread (up to 64 live workers per process). Requires --allow-read for the target module path. Methods and events: postMessage(value, transferOrOptions?), terminate(), and message, error, and close events.

self · name · postMessage(value, transferOrOptions?) · close()

Globals available inside a worker thread, alongside all built-in modules and inherited permissions.

structuredClone(value, { transfer }?)

Deep-clone primitives, plain objects, arrays, Map, Set, Date, RegExp, standard Error types, ArrayBuffer (including resizable and immutable), and TypedArrays/DataViews while preserving cycles and shared references. Limits: 16 MiB binary data per message/clone, 64 MiB queued per worker direction, and 32,768 graph nodes/entries. Listed transferable ArrayBuffers are copied and detached on the sender.

Timers, events, and encoding

setTimeout(fn, ms = 0, ...args) · clearTimeout(id) · setInterval(fn, ms = 0, ...args) · clearInterval(id) · setImmediate(fn, ...args) · clearImmediate(id) · queueMicrotask(fn)

Timers backed by nanosecond native deadlines on kqueue/epoll (with a 1 ms minimum JS delay), next-turn immediates, and microtask scheduling.

performance: { now(), timeOrigin }

Monotonic high-resolution millisecond clock.

Event · EventTarget · MessageEvent · ErrorEvent · PromiseRejectionEvent · AbortController · AbortSignal

Standard event classes, global addEventListener / removeEventListener / dispatchEvent, and AbortSignal.abort(), AbortSignal.timeout(ms), and AbortSignal.any(signals).

TextEncoder · TextDecoder · btoa(str) · atob(b64)

Native UTF-8 encoding/decoding (including encodeInto, fatal, and ignoreBOM) and Base64 helpers.

DOMException · SystemError · onunhandledrejection

Failed system and permission operations reject or throw a SystemError carrying an errno or runtime code (such as "ENOENT" or "PERMISSION_DENIED", where err.name is "PermissionDenied"). Unhandled promise rejections fire a cancelable unhandledrejection event on globalThis and exit the process with status 1 unless event.preventDefault() is called.
