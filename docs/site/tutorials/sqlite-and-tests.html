Query SQLite and run tests

Store records with the built-in sqlite module, manage connection and statement lifetimes with using, and verify behavior with bkr test.

1. Create a database helper module

The optional sqlite module loads the system SQLite library (3.31+) at startup. In-memory databases (new Database() or ":memory:") require no filesystem permissions. Create todos.ts: 

import { Database } from "sqlite";

export function openTodos(path = ":memory:") {
  const db = new Database(path);
  db.exec(`
    CREATE TABLE IF NOT EXISTS todos (
      id INTEGER PRIMARY KEY,
      title TEXT NOT NULL,
      done INTEGER NOT NULL DEFAULT 0
    )
  `);

  const insert = db.prepare("INSERT INTO todos (title) VALUES (:title)");
  const byId = db.prepare("SELECT id, title, done FROM todos WHERE id = ?");
  const listAll = db.prepare("SELECT id, title, done FROM todos ORDER BY id");

  const addBatch = db.transaction((titles: string[]) => {
    for (const title of titles) insert.run({ title });
  });

  return {
    db,
    add(title: string) {
      const { lastInsertRowid } = insert.run({ title });
      return byId.get(lastInsertRowid);
    },
    addBatch,
    all() {
      return listAll.all();
    },
    [Symbol.dispose]() {
      db.close();
    },
  };
}

Closing a Database finalizes its prepared statements. Implementing Symbol.dispose lets callers bind the wrapper with using so the connection closes on scope exit.

2. Write a test suite

Create todos.test.ts using the built-in test module:

import { test, describe, assertEquals, assertThrows } from "test";
import { openTodos } from "./todos.ts";

describe("todos", () => {
  test("inserts and queries rows", () => {
    using store = openTodos();
    const item = store.add("Write docs");
    assertEquals(item, { id: 1, title: "Write docs", done: 0 });
  });

  test("rolls back failed transactions", () => {
    using store = openTodos();
    assertThrows(() => {
      store.addBatch(["First", null as  unknown as string]);
    });
    assertEquals(store.all(), []);
  });
});

3. Run the test runner

Run bkr test on the file (or omit the path to discover all *.test.*, *_test.*, and *.spec.* files under the working directory):

./out/bkr test todos.test.ts

Expected output:

todos.test.ts
  ✓ todos > inserts and queries rows (0.45 ms)
  ✓ todos > rolls back failed transactions (0.31 ms)

2 passed (1.82 ms)

Pass --filter=rolls to run matching tests only, or --watch to rerun in a fresh process whenever a file changes.

4. Persist to a file on disk

Opening a file-backed SQLite database checks permissions for the database file and its -journal, -wal, and -shm sidecars. Grant both --allow-read and --allow-write on the directory holding the database: 

mkdir -p ./data
./out/bkr --allow-read=./data --allow-write=./data app.ts
