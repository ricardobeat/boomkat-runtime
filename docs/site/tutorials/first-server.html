Your first HTTP server with bkr

Build bkr, inspect a module's required permissions with bkr check, and serve HTTP routes with scoped network and file grants.

Prerequisites

Install a release binary with the install script, or build from source alongside the ../boomkat repository with c3c (v0.8.5+) and OpenSSL 3:

# Install a release binary
curl https://boomkat.run/install | sh

# Or build from source
bash scripts/build_uws.sh
c3c build bkr

Building from source writes the binary to out/bkr.

1. Write a basic HTTP server

Create server.ts:

import { serve } from "http";

serve({
  hostname: "127.0.0.1",
  port: 8080,
  routes: {
    "/health": new Response("OK"),
    "/hello/:name": (req) => Response.json({ hello: req.params.name }),
  },
});

console.log("Listening on http://127.0.0.1:8080");

2. Inspect required permissions

Run bkr check to see which built-in modules the entry point imports and which permission flags they need:

./out/bkr check server.ts

Expected output:

1 modules scanned
  http -> net
try: --allow-net

3. Start the server with a scoped network grant

Every capability is denied until granted. Pass --allow-net=127.0.0.1:8080 so the script can bind only to that loopback address and port:

./out/bkr --allow-net=127.0.0.1:8080 server.ts

In another terminal, test the routes:

curl http://127.0.0.1:8080/health
curl http://127.0.0.1:8080/hello/margay

Expected output:

OK
{"hello":"margay"}

4. Stream a file from disk

Use file.body(path) to stream a file with bounded 64 KiB reads and socket backpressure. Create note.txt and add a route to server.ts:

import { serve } from "http";
import { body } from "file";

serve({
  hostname: "127.0.0.1",
  port: 8080,
  routes: {
    "/health": new Response("OK"),
    "/note": () => new Response(body("./note.txt")),
  },
});

Grant read access to note.txt alongside the network grant:

./out/bkr --allow-net=127.0.0.1:8080 --allow-read=./note.txt server.ts
