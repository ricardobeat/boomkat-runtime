Validation:
- 63 differential API cases agree with the saved baseline: URL parsing/coercion, subclasses and foreign new.target, public field/accessor/prototype changes, patched String/slice/parser functions, custom hasInstance, proxies, readonly fields, Response types/options and allocation churn.
- Full HTTP lifecycle/native-body suite passes in release and optimized ASAN (O3, POOL_BYPASS). Request/response layout mutations, captured URL/headers and retained Requests pass in release and optimized ASAN.
- Targeted API and layout tests pass in ASAN with GC_STRESS, GC_VERIFY and POOL_BYPASS (bounded churn of 300 iterations).
- Release HTTP Response retention stress: 5.9 MiB RSS growth, within the 32 MiB bound.
- Seven focused engine descriptor/mapped-argument regressions and 42 Rosetta cases pass.
- Python syntax, C3 formatting and diff whitespace checks pass.

Correctness fixes:
- Object.defineProperty replacement of existing data slots acquires the new string reference and releases the old one, including mapped argument replacements. Native Response allocation timing exposed a use-after-free of a retained Request method string in the old implementation; optimized ASAN confirmed the string was reclaimed during sweeping. The fix is commit 632a6852 in boomkat-perf and is also cherry-picked onto engine main as 27ced8f5.
- Shared URL fast parser checks the end of the input before reading a second dot.
- Native installation validates arguments, rejects repeated installation and checks persistent key/root allocation.

Limits:
- Native paths handle the common supported cases; complex URLs, coercion, custom instance checks, prototype setters and complex Response options use JS initializers. This preserves current runtime behavior rather than extending web API conformance.
- Full forced-GC streaming retention has a previously recorded baseline incremental reachability failure (see bench/http-layout-results.txt); this work does not claim to resolve that separate collector issue.
- Native implementation and validation artifacts are retained in runtime. The engine ownership fix is commit 632a6852 in boomkat-perf and 27ced8f5 on engine main. Existing test/report artifacts from earlier experiments are preserved.
